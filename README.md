# Primavera amarilla 🌼

Una pequeña web interactiva de primavera. Las flores amarillas crecen continuamente y se pueden tocar; el desafío consiste en juntar 12 flores en 30 segundos mientras se esquivan los yuyos.

## Uso

Abrí `index.html` en el navegador. No requiere instalación, cuentas ni compilación.

## Publicación en GitHub Pages

En el repositorio, abrí **Settings → Pages**, elegí **Deploy from a branch**, rama **main** y carpeta **/(root)**. Guardá los cambios. La URL tendrá el formato `https://USUARIO.github.io/NOMBRE-DEL-REPO/`.

La web utiliza HTML, CSS y JavaScript. Las tipografías se cargan desde Google Fonts cuando hay conexión, con tipografías de respaldo sin conexión.
